NovaPOS PWA
===========
Uruchomienie:
1. Umieść wszystkie pliki na hostingu obsługującym HTTPS.
2. Otwórz adres w Safari na iPadzie.
3. Udostępnij -> Dodaj do ekranu początkowego.
4. Uruchom ikonę NovaPOS.
